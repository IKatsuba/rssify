# Code of Conduct

rssify adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), including its standards, scope, enforcement responsibilities, and enforcement guidelines. The full linked code applies to this community and anyone representing it.

Be respectful, give constructive feedback, and respect people's privacy. Harassment, discrimination, threats, and sharing private information without consent are unacceptable.

Report incidents privately to the repository owner; GitHub private reporting through **Security → Advisories → Report a vulnerability** is also available when enabled. Maintainers will review reports fairly, protect reporters' privacy, and apply the Covenant's correction, warning, temporary ban, or permanent ban guidelines as appropriate.
